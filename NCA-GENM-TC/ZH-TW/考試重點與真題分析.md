## 🔥 真題考點分析（來自 ExamTopics 公開題目）

### ✅ 確認必考主題

#### 1. CNN 影像分類
**真題**：You need to classify labeled images of cats and dogs. Which algorithm is commonly used?
**答案**：Convolutional Neural Networks (CNN)
- CNN 是影像分類的標準方法
- 使用卷積層提取空間特徵
- 比 Decision Trees、K-Means、Linear Regression 更適合影像

#### 2. ML 專案步驟
**真題**：What is the correct order of steps in an ML project?
**答案**：Data collection → Data preprocessing → Model training → Model evaluation
- 資料收集第一步
- 資料預處理（清洗、正規化）
- 模型訓練
- 模型評估

#### 3. GAN 判別器角色
**真題**：In a GAN, what is the role of the discriminator?
**答案**：To distinguish between real and generated data
- Generator：從噪音生成假資料
- Discriminator：分辨真實 vs 生成的資料
- 兩者對抗訓練（minimax game）

#### 4. U-Net 在 Diffusion Models 中的作用
**真題**：What is the significance of using a U-Net like architecture in denoising diffusion probabilistic models?
**答案**：To generate new images from pure noise
- U-Net 是 Diffusion Model 的骨幹網路
- 負責在每個 timestep 預測並移除噪音
- 最終從純噪音生成清晰影像

## 📋 Topic 2: Image Generation and Computer Vision — 必背重點

### 2.1 GAN（Generative Adversarial Network）★★★

#### GAN 架構（已出真題）
```
Generator(z) → Fake Image
                    ↓
Discriminator ← Real Image
    ↓
Real/Fake 判斷 → 回饋到 Generator
```

#### GAN 變體
| 變體 | 特點 | 應用 |
|------|------|------|
| DCGAN | 深度卷積 GAN | 穩定訓練 |
| StyleGAN | 風格控制 | 人臉生成 |
| CycleGAN | 無配對轉換 | 風格遷移 |
| Pix2Pix | 有配對轉換 | 圖到圖翻譯 |
| WGAN | Wasserstein 距離 | 穩定性改善 |
| Progressive GAN | 逐步增加解析度 | 高解析生成 |

#### GAN 訓練挑戰
- **Mode Collapse**: Generator 只生成少數模式
- **Training Instability**: G 和 D 不平衡
- **Vanishing Gradients**: D 太強導致 G 無法學習

### 2.2 VAE（Variational Autoencoder）
| 組件 | 功能 |
|------|------|
| Encoder | 輸入 → latent distribution (μ, σ) |
| Reparameterization | z = μ + σ × ε |
| Decoder | latent → 重建輸出 |
| Loss | Reconstruction + KL Divergence |

### 2.3 Vision Transformer (ViT)
- 將影像切割成 patches（如 16×16）
- 每個 patch 做 linear projection 成為 token
- 加入 position embedding
- 用標準 Transformer encoder 處理
- [CLS] token 用於分類

## 📋 Topic 3: Diffusion Models — 必背重點（★★★ 超級重要）

### 3.1 擴散模型基礎（已出真題）

#### 兩個過程
| 過程 | 說明 | 數學 |
|------|------|------|
| Forward (Diffusion) | 逐步加噪音 | x_t = √(α_t) x_0 + √(1-α_t) ε |
| Reverse (Denoising) | 逐步去噪音 | 學習 p(x_{t-1} \| x_t) |

#### U-Net 在 Diffusion 中的角色（★★★ 已出真題）
- 預測每個 timestep 的噪音 ε
- 輸入：noisy image x_t + timestep t
- 輸出：predicted noise ε_θ
- Skip connections 保留細節資訊
- 從純噪音經過 T 步去噪生成影像

### 3.2 重要 Diffusion 模型
| 模型 | 開發者 | 特點 |
|------|--------|------|
| **DDPM** | UC Berkeley | 基礎框架 |
| **DDIM** | Stanford | 加速採樣 |
| **Stable Diffusion** | Stability AI | Latent space diffusion |
| **DALL-E 2/3** | OpenAI | 文字到影像 |
| **Midjourney** | Midjourney | 高美學品質 |
| **Imagen** | Google | 文字理解強 |
| **SDXL** | Stability AI | 高解析度 |

### 3.3 Latent Diffusion（★★★ 重點）
```
Image → Encoder → Latent Space → Diffusion Process → Decoder → Generated Image
                                    ↑
                              Text Conditioning (CLIP)
```
- 在 latent space 做 diffusion（非 pixel space）
- 大幅減少計算量
- VAE Encoder/Decoder 處理 pixel↔latent 轉換
- Cross-attention 注入 text conditioning

### 3.4 Conditioning 方法
| 方法 | 說明 |
|------|------|
| **Classifier Guidance** | 用外部分類器引導生成 |
| **Classifier-Free Guidance (CFG)** | 同時訓練有條件/無條件，推理時混合 |
| **Cross-Attention** | 文字 embedding 注入 U-Net |
| **ControlNet** | 空間控制（邊緣、深度、姿勢） |
| **IP-Adapter** | 影像條件控制 |

### 必記流程
- **Diffusion Forward**: 逐步加噪音
- **Diffusion Reverse**: 逐步去噪音（U-Net 預測噪音）
- **Stable Diffusion**: Text→CLIP→Cross-Attention→U-Net（Latent）→Decoder
- **GAN Training**: G 生成假圖 → D 判別真假 → 對抗學習
- **CLIP Training**: Image-Text 對比學習（最大化匹配對相似度）
