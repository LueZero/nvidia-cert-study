### 1.1 神經網路基礎 (Neural Networks)

#### 感知機與多層感知機 (Perceptron & MLP)

神經網路的基本單元是**感知機 (Perceptron)**，模擬生物神經元的運算：

```
輸入層          隱藏層          輸出層
  x₁ ──w₁──┐
             ├──→ [Σ + b] → f(z) → ŷ
  x₂ ──w₂──┘

  z = Σ(wᵢ · xᵢ) + b
  ŷ = f(z)    ← 激活函數
```

**多層感知機 (MLP)** 由多個全連接層堆疊而成：

| 層級 | 功能 | 範例維度 |
|------|------|----------|
| 輸入層 | 接收原始特徵 | 784 (28×28 圖片) |
| 隱藏層 1 | 特徵提取 | 512 |
| 隱藏層 2 | 抽象表示 | 256 |
| 輸出層 | 最終預測 | 10 (分類數) |

#### 激活函數 (Activation Functions)

| 函數 | 公式 | 特點 | 使用場景 |
|------|------|------|----------|
| ReLU | $f(x) = \max(0, x)$ | 計算快、緩解梯度消失 | 隱藏層首選 |
| Sigmoid | $f(x) = \frac{1}{1+e^{-x}}$ | 輸出 [0,1] | 二元分類輸出 |
| Tanh | $f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 輸出 [-1,1] | RNN 常用 |
| GELU | $f(x) = x \cdot \Phi(x)$ | 平滑非線性 | Transformer 標配 |
| Swish | $f(x) = x \cdot \sigma(x)$ | 自適應平滑 | 深層網路 |
| Softmax | $f(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}$ | 機率分佈 | 多分類輸出 |

```python
import torch
import torch.nn as nn

# 常見激活函數使用
model = nn.Sequential(
    nn.Linear(784, 512),
    nn.ReLU(),           # 隱藏層使用 ReLU
    nn.Linear(512, 256),
    nn.GELU(),           # Transformer 風格使用 GELU
    nn.Linear(256, 10),
    nn.Softmax(dim=1)    # 多分類輸出
)
```

#### 損失函數 (Loss Functions)

| 損失函數 | 公式 | 適用任務 | 用途與應用 |
|----------|------|----------|-----------|
| MSE | $L = \frac{1}{n}\sum(y - \hat{y})^2$ | 迴歸 | 預測連續值（房價、溫度）；對大誤差懲罰重 |
| Cross-Entropy | $L = -\sum y_i \log(\hat{y}_i)$ | 分類 | 多分類模型最終層（ImageNet、文本分類） |
| Binary CE | $L = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ | 二元分類 | 是/否決策（垃圾郵件偵測、醫療診斷） |
| Contrastive Loss | $L = -\log\frac{e^{sim(z_i,z_j)/\tau}}{\sum_k e^{sim(z_i,z_k)/\tau}}$ | CLIP、對比學習 | 多模態對齊（圖文配對、語義搜索） |
| Diffusion Loss | $L = \lVert\epsilon - \epsilon_\theta(x_t, t)\rVert^2$ | 擴散模型 | 圖像/影片生成（Stable Diffusion、DALL-E） |

### 1.3 序列模型 (RNN/LSTM)

#### RNN 基本結構

```
   x₁        x₂        x₃        x₄
    ↓         ↓         ↓         ↓
┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐
│  h₁  │→│  h₂  │→│  h₃  │→│  h₄  │→ ...
└──────┘  └──────┘  └──────┘  └──────┘
    ↓         ↓         ↓         ↓
   y₁        y₂        y₃        y₄

hₜ = tanh(Wₕhₜ₋₁ + Wₓxₜ + b)
```

**RNN 問題：** 梯度消失/爆炸，難以捕捉長距離依賴。

#### LSTM (Long Short-Term Memory)

```
┌─────────────────────────────────────────┐
│              LSTM Cell                    │
│                                          │
│  遺忘門: fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf)    │
│  輸入門: iₜ = σ(Wi·[hₜ₋₁, xₜ] + bi)    │
│  候選值: C̃ₜ = tanh(Wc·[hₜ₋₁, xₜ] + bc) │
│  記憶更新: Cₜ = fₜ⊙Cₜ₋₁ + iₜ⊙C̃ₜ       │
│  輸出門: oₜ = σ(Wo·[hₜ₋₁, xₜ] + bo)    │
│  隱藏態: hₜ = oₜ⊙tanh(Cₜ)              │
└─────────────────────────────────────────┘
```

### 1.4 Transformer 架構

#### Self-Attention 機制

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

> **用途**：讓序列中每個 token 動態計算對其他 token 的關注度，用於 NLP（翻譯、摘要）、CV（ViT 圖像理解）及所有 Transformer 類模型。除以 $\sqrt{d_k}$ 防止點積過大導致 softmax 梯度消失。

```
      Input Embeddings
           ↓
    ┌──────┼──────┐
    ↓      ↓      ↓
   W_Q    W_K    W_V
    ↓      ↓      ↓
    Q      K      V
    │      │      │
    └──┬───┘      │
       ↓          │
   Q·K^T/√dk     │
       ↓          │
   Softmax        │
       ↓          │
       └────×─────┘
            ↓
      Attention Output
```

#### Multi-Head Attention

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, n_heads=8):
        super().__init__()
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)
        # 線性投影並分割成多頭
        Q = self.W_q(Q).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(K).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(V).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        
        # 計算注意力分數
        scores = torch.matmul(Q, K.transpose(-2, -1)) / (self.d_k ** 0.5)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)
        attn = torch.softmax(scores, dim=-1)
        
        # 加權求和
        output = torch.matmul(attn, V)
        output = output.transpose(1, 2).contiguous().view(batch_size, -1, self.n_heads * self.d_k)
        return self.W_o(output)
```

#### 完整 Transformer 架構

```
┌───────────────────────────────────────────┐
│              Transformer                   │
│                                           │
│  ┌─────────────┐    ┌─────────────┐      │
│  │   Encoder    │    │   Decoder    │      │
│  │             │    │             │      │
│  │ Multi-Head  │    │ Masked MHA  │      │
│  │ Attention   │    │      ↓      │      │
│  │     ↓       │───→│ Cross-Attn  │      │
│  │ Feed Forward│    │      ↓      │      │
│  │     ↓       │    │ Feed Forward│      │
│  │ Layer Norm  │    │      ↓      │      │
│  │  + Residual │    │ Layer Norm  │      │
│  └─────────────┘    └─────────────┘      │
│       ×N                  ×N              │
└───────────────────────────────────────────┘
```

**Positional Encoding：**

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$
$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

> **用途**：Transformer 無遞迴結構，需透過位置編碼注入 token 順序資訊。正弦/餘弦函數使模型能學習相對位置關係，且理論上可外推至比訓練更長的序列。

### 1.5 訓練流程與最佳化

#### 優化器比較

| 優化器 | 更新規則 | 特點 |
|--------|----------|------|
| SGD | $\theta = \theta - \eta \nabla L$ | 基礎、需手動調 LR |
| Momentum | $v = \gamma v + \eta \nabla L$ | 加速收斂 |
| Adam | 結合 Momentum + RMSprop | 自適應學習率、最常用 |
| AdamW | Adam + Weight Decay | Transformer 標配 |
| LAMB | Layer-wise Adaptive | 大 batch 訓練 |

#### 學習率排程 (Learning Rate Schedule)

```
學習率
  │    Warmup    Cosine Decay
  │      /\
  │     /  \
  │    /    ╲
  │   /      ╲
  │  /        ╲___________
  │ /
  └──────────────────────── Steps
  0   warmup   T_max
```

```python
from torch.optim.lr_scheduler import CosineAnnealingWarmRestarts, OneCycleLR

# Cosine Annealing with Warm Restarts
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
scheduler = CosineAnnealingWarmRestarts(optimizer, T_0=10, T_mult=2)

# OneCycleLR (適用於快速訓練)
scheduler = OneCycleLR(optimizer, max_lr=1e-3, total_steps=1000)
```

#### Batch Size 與訓練穩定性

| Batch Size | 優點 | 缺點 |
|------------|------|------|
| 小 (16-32) | 正則化效果、記憶體少 | 訓練慢、不穩定 |
| 中 (64-256) | 平衡效率與效果 | - |
| 大 (512+) | GPU 效率高、穩定 | 需大 LR、泛化可能差 |

**大 Batch 技巧：** Linear Scaling Rule → LR 隨 batch size 線性增長

### 2.2 CLIP (Contrastive Language-Image Pre-training)

#### CLIP 架構

```
┌──────────────────────────────────────────────────┐
│                    CLIP                            │
│                                                   │
│  ┌─────────────┐           ┌─────────────┐       │
│  │ Image       │           │ Text        │       │
│  │ Encoder     │           │ Encoder     │       │
│  │ (ViT/ResNet)│           │(Transformer)│       │
│  └──────┬──────┘           └──────┬──────┘       │
│         ↓                         ↓              │
│  ┌─────────────┐           ┌─────────────┐       │
│  │ Image       │           │ Text        │       │
│  │ Embedding   │           │ Embedding   │       │
│  │   I₁...Iₙ   │           │   T₁...Tₙ   │       │
│  └──────┬──────┘           └──────┬──────┘       │
│         └──────────┬───────────────┘              │
│                    ↓                              │
│         ┌─────────────────┐                      │
│         │ Cosine Similarity│                      │
│         │    Matrix N×N    │                      │
│         └─────────────────┘                      │
│                    ↓                              │
│         Contrastive Loss                          │
│         (對角線=正對, 其餘=負對)                   │
└──────────────────────────────────────────────────┘
```

#### CLIP 對比學習目標

$$\mathcal{L} = -\frac{1}{2N}\sum_{i=1}^{N}\left[\log\frac{e^{sim(I_i, T_i)/\tau}}{\sum_{j=1}^{N}e^{sim(I_i, T_j)/\tau}} + \log\frac{e^{sim(T_i, I_i)/\tau}}{\sum_{j=1}^{N}e^{sim(T_i, I_j)/\tau}}\right]$$

> **用途**：CLIP 的雙向對比損失——使配對的圖文嵌入向量靠近、非配對的遠離。應用於 zero-shot 圖像分類、圖文檢索、引導生成模型（CLIP-guided Diffusion）。$\tau$ 為溫度參數，控制分佈的銳利度。

```python
import torch
import clip
from PIL import Image

# 載入 CLIP 模型
device = "cuda"
model, preprocess = clip.load("ViT-B/32", device=device)

# Zero-shot 分類
image = preprocess(Image.open("cat.jpg")).unsqueeze(0).to(device)
text = clip.tokenize(["a cat", "a dog", "a bird"]).to(device)

with torch.no_grad():
    image_features = model.encode_image(image)
    text_features = model.encode_text(text)
    
    # 正規化
    image_features /= image_features.norm(dim=-1, keepdim=True)
    text_features /= text_features.norm(dim=-1, keepdim=True)
    
    # 計算相似度
    similarity = (100.0 * image_features @ text_features.T).softmax(dim=-1)
    print(f"預測機率: {similarity}")  # 例: [0.95, 0.03, 0.02]
```

**CLIP 應用場景：**
- Zero-shot 圖像分類（無需訓練資料）
- 圖文檢索（Image-Text Retrieval）
- 引導生成模型（CLIP-guided Diffusion）
- 多模態 Embedding 空間對齊

### 2.3 多模態融合策略

#### 三種融合策略比較

```
Early Fusion (早期融合)          Late Fusion (晚期融合)
┌───┐ ┌───┐                    ┌───┐    ┌───┐
│Img│ │Txt│                    │Img│    │Txt│
└─┬─┘ └─┬─┘                    └─┬─┘    └─┬─┘
  │     │                        ↓        ↓
  └──┬──┘ ← 輸入層合併         Encoder  Encoder
     ↓                           ↓        ↓
  Encoder                      Embed    Embed
     ↓                           └──┬──┘
  Output                            ↓ ← 決策層合併
                                 Output
```

## 📘 領域 3：生成式模型 (~20%)

### 3.1 擴散模型 (Diffusion Models)

#### 前向擴散過程 (Forward Process)

逐步加入高斯噪聲，從乾淨數據 $x_0$ 到純噪聲 $x_T$：

$$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} \cdot x_{t-1}, \beta_t \mathbf{I})$$

直接計算任意步驟：

$$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1-\bar{\alpha}_t} \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

其中 $\bar{\alpha}_t = \prod_{s=1}^{t}(1-\beta_s)$

```
Forward Process (加噪)
x₀ ──→ x₁ ──→ x₂ ──→ ... ──→ x_T
清晰      +噪聲   +更多噪聲       純噪聲
🖼️                                  ⬜
```

#### 反向擴散過程 (Reverse Process)

模型學習預測噪聲 $\epsilon_\theta$，逐步去噪：

$$p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2 \mathbf{I})$$

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}}\epsilon_\theta(x_t, t)\right)$$

```
Reverse Process (去噪) — 模型學習的方向
x_T ──→ x_{T-1} ──→ ... ──→ x₁ ──→ x₀
純噪聲                              清晰圖片
⬜                                  🖼️
```

#### 訓練目標

$$\mathcal{L}_{simple} = \mathbb{E}_{t, x_0, \epsilon}\left[\lVert\epsilon - \epsilon_\theta(x_t, t)\rVert^2\right]$$

> **用途**：擴散模型（Stable Diffusion、DALL-E 3）的核心訓練目標——教模型預測加入的噪聲 $\epsilon$，推論時反向逐步去噪即可生成圖像/影片。

```python
import torch
from diffusers import DDPMScheduler, UNet2DModel

# 簡化的 DDPM 訓練迴圈
noise_scheduler = DDPMScheduler(num_train_timesteps=1000)
model = UNet2DModel(sample_size=64, in_channels=3, out_channels=3)

for batch in dataloader:
    clean_images = batch["images"]
    noise = torch.randn_like(clean_images)
    timesteps = torch.randint(0, 1000, (batch_size,))
    
    # 加噪
    noisy_images = noise_scheduler.add_noise(clean_images, noise, timesteps)
    
    # 預測噪聲
    noise_pred = model(noisy_images, timesteps).sample
    
    # 損失
    loss = torch.nn.functional.mse_loss(noise_pred, noise)
    loss.backward()
    optimizer.step()
```

### 3.3 Classifier-Free Guidance (CFG)

$$\epsilon_{guided} = \epsilon_{uncond} + s \cdot (\epsilon_{cond} - \epsilon_{uncond})$$

> **用途**：控制擴散模型生成結果與文字提示的匹配程度。$s$ 越大，生成圖片越忠實於 prompt 但多樣性降低。Stable Diffusion、Midjourney、DALL-E 3 皆使用 CFG，典型值 $s = 7.0\text{-}8.5$ 可兼顧品質與提示忠實度。

| Guidance Scale (s) | 效果 |
|-------------------|------|
| 1.0 | 無引導，多樣性高 |
| 3.0-5.0 | 平衡品質與多樣性 |
| 7.0-8.5 | 高品質、符合提示 |
| 12.0+ | 過飽和、可能扭曲 |

| 精度 | 位元 | 記憶體 | 速度 | 品質損失 |

### 4.2 知識蒸餾 (Knowledge Distillation)

```
┌─────────────────────────────────────┐
│        Knowledge Distillation        │
│                                     │
│  ┌──────────────┐                   │
│  │ Teacher Model │  (大模型，高精度) │
│  │   (Frozen)    │                   │
│  └──────┬───────┘                   │
│         ↓                           │
│   Soft Predictions (溫度 T>1)        │
│         ↓                           │
│   KL Divergence Loss                 │
│         ↓                           │
│  ┌──────────────┐                   │
│  │ Student Model │  (小模型，高效率) │
│  │  (Training)   │                   │
│  └──────────────┘                   │
│                                     │
│  L = α·L_CE(y, ŷ) + (1-α)·L_KL    │
└─────────────────────────────────────┘
```

$$\mathcal{L}_{KD} = \alpha \cdot \text{CE}(y, \hat{y}_{student}) + (1-\alpha) \cdot T^2 \cdot \text{KL}(p_{teacher}^T \| p_{student}^T)$$

> **用途**：知識蒸餾損失——用溫度 $T$ 軟化 Teacher 輸出分佈，讓 Student 模型學到更豐富的「暗知識」(dark knowledge)。應用於模型壓縮部署（如手機端部署、邊緣推論加速），在精度損失極小的情況下大幅縮小模型。

### 4.5 混合精度訓練 (Mixed Precision / AMP)

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()

for batch in dataloader:
    optimizer.zero_grad()
    
    # Forward pass 使用 FP16
    with autocast():
        output = model(batch["input"])
        loss = criterion(output, batch["target"])
    
    # Backward pass 使用 Loss Scaling
    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
```

```
混合精度訓練流程：
┌──────────┐     ┌──────────┐     ┌──────────┐
│ FP32     │     │ FP16     │     │ FP32     │
│ Master   │ ──→ │ Forward  │ ──→ │ Weight   │
│ Weights  │     │ + Loss   │     │ Update   │
└──────────┘     └──────────┘     └──────────┘
                       ↓
                 Loss Scaling
                 (防止 FP16 下溢)
```

**效益：**
- 記憶體減少約 50%
- 訓練速度提升 1.5-3×（在 Tensor Cores 上）
- 精度損失可忽略

### 4.6 推論最佳化

#### KV-Cache

```
Without KV-Cache (每次重新計算):
Step 1: 計算 [A]
Step 2: 計算 [A, B]        ← 重算 A
Step 3: 計算 [A, B, C]    ← 重算 A, B
→ O(n²) 計算量

With KV-Cache (快取已計算的 K, V):
Step 1: 計算 [A], 快取 K_A, V_A
Step 2: 計算 [B], 用快取的 K_A, V_A
Step 3: 計算 [C], 用快取的 K_AB, V_AB
→ O(n) 計算量
```

#### 其他推論技巧

| 技術 | 說明 | 效果 |

| Dynamic Batching | 動態合併請求 | 提高吞吐 |
| Continuous Batching | 不等所有請求完成 | 降低延遲 |
| Speculative Decoding | 小模型草稿 + 大模型驗證 | 2-3× 加速 |
| PagedAttention | vLLM 的記憶體管理 | 減少浪費 |
| Flash Attention | 最佳化注意力計算 | 2-4× 加速 |

```python
import optuna

def objective(trial):
    lr = trial.suggest_float("lr", 1e-6, 1e-3, log=True)
    batch_size = trial.suggest_categorical("batch_size", [16, 32, 64, 128])
    warmup_ratio = trial.suggest_float("warmup_ratio", 0.0, 0.2)

                       warmup_ratio=warmup_ratio, weight_decay=weight_decay)
```

#### Differential Privacy (差分隱私)

$$\Pr[\mathcal{M}(D) \in S] \leq e^\epsilon \cdot \Pr[\mathcal{M}(D') \in S] + \delta$$

> **用途**：數學上保證模型輸出不會洩漏任何單一訓練樣本的資訊。應用於醫療 AI（保護病患隱私）、金融模型（保護客戶資料）、聯邦學習中的隱私保護。Apple、Google 等公司用於保護用戶數據的同時進行模型訓練。

- $\epsilon$：隱私預算（越小越私密）
- $\delta$：允許的失敗機率
- 實作：梯度裁剪 + 高斯噪聲注入

```python
# 使用 Opacus 進行差分隱私訓練
from opacus import PrivacyEngine

privacy_engine = PrivacyEngine()
model, optimizer, dataloader = privacy_engine.make_private(
    module=model,
    optimizer=optimizer,
    data_loader=dataloader,
    noise_multiplier=1.1,      # 噪聲倍率
    max_grad_norm=1.0,         # 梯度裁剪
)

# 訓練後查詢隱私消耗
epsilon = privacy_engine.get_epsilon(delta=1e-5)
print(f"ε = {epsilon:.2f}")  # 例: ε = 3.42
```
