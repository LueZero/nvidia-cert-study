## 📘 主題 1：核心機器學習與 AI 知識

### 1.1 深度學習基礎回顧

**訓練流程核心：**
- 前向傳播 → 計算損失 → 反向傳播 → 梯度更新
- **損失函數**：交叉熵（分類）、MSE（迴歸）、對比損失（對比學習）
- **正則化**：L2、Dropout、Data Augmentation、Early Stopping
- **批次正規化（Batch Normalization）**：穩定訓練、加速收斂

### 1.2 卷積神經網路（CNN）基礎

| 層 | 功能 |
|----|------|
| **卷積層（Conv）** | 提取局部特徵（邊緣、紋理、形狀） |
| **池化層（Pooling）** | 降低空間維度，增加感受野 |
| **全連接層（FC）** | 最終分類或迴歸輸出 |

**經典架構演進：**
- AlexNet → VGGNet → GoogLeNet → ResNet → EfficientNet

**ResNet 貢獻**：殘差連接（Skip Connection）解決深層網路的梯度消失問題

### 1.3 Transformer 架構（多模態核心）

**關鍵組件：**
- **Self-Attention**：計算序列中每個元素與其他元素的關聯
- **Cross-Attention**：跨不同模態計算注意力（文字關注影像）
- **Vision Transformer（ViT）**：將影像切割成 patch 序列，使用 Transformer 處理

## 📘 主題 2：多模態模型架構

### 2.1 什麼是多模態 AI

多模態 AI 系統能同時理解和生成多種資料類型：
- **文字（Text）**
- **影像（Image）**
- **音訊（Audio）**
- **影片（Video）**

### 2.2 核心多模態模型

#### CLIP（Contrastive Language-Image Pre-training）
```
影像 → 影像編碼器（ViT） → 影像向量 ┐
                                      ├→ 對比學習（使配對的影像-文字向量接近）
文字 → 文字編碼器（Transformer）→ 文字向量 ┘
```
- **訓練方式**：對比學習，拉近配對的影像-文字，推開不配對的
- **能力**：零樣本影像分類、影像-文字檢索
- **特點**：不需要人工標註的分類標籤

#### Vision Transformer（ViT）
```
影像 → 切割成 16×16 的 patch → 展平 + 位置編碼 → Transformer Encoder → 分類
```
- 將影像視為 patch 序列，直接使用 Transformer 處理
- 在大規模資料集上超越 CNN

#### 多模態 LLM（如 GPT-4V、LLaVA）
```
影像 → 視覺編碼器 → 視覺 token ┐
                                ├→ LLM → 文字輸出
文字 → Tokenizer → 文字 token ─┘
```
- 將影像編碼為 token 序列，與文字 token 一起輸入 LLM
- 能回答關於影像的問題

### 2.3 跨模態融合策略

| 策略 | 說明 | 範例 |
|------|------|------|
| **Early Fusion** | 在輸入層融合不同模態 | 直接連接特徵向量 |
| **Late Fusion** | 各模態獨立處理，最後合併結果 | 分別提取特徵再組合 |
| **Cross-Attention** | 用注意力機制跨模態交互 | 文字查詢影像特徵 |
| **中間融合** | 在中間層進行跨模態交互 | 多層逐步融合 |

## 📘 主題 3：生成式模型

### 3.1 Diffusion Models（擴散模型）

**核心概念：**
```
前向過程（加噪音）：乾淨影像 x₀ → x₁ → x₂ → ... → xₜ（純噪音）
反向過程（去噪音）：xₜ（噪音）→ xₜ₋₁ → ... → x₁ → x₀（生成影像）
```

- **前向過程**：逐步對影像添加高斯噪音
- **反向過程**：神經網路學習預測並去除噪音
- **U-Net**：常用的去噪網路架構
- **優於 GAN**：訓練更穩定、生成品質更高、更多樣化

**Stable Diffusion 架構：**
```
文字提示 → CLIP 文字編碼器 → 文字嵌入
                                  ↓
              潛空間 (Latent Space) 中的 U-Net 去噪
                                  ↓
              VAE 解碼器 → 生成的影像
```

**關鍵技術：**
| 技術 | 說明 |
|------|------|
| **Latent Diffusion** | 在壓縮的潛空間中進行擴散，降低運算成本 |
| **Classifier-Free Guidance** | 增強文字控制力，提高影像與提示的一致性 |
| **ControlNet** | 添加空間控制條件（姿勢、邊緣、深度圖） |
| **SDXL** | Stable Diffusion 的改進版，更高品質 |

### 3.2 GAN（Generative Adversarial Network）

```
隨機噪音 → 生成器（Generator）→ 假影像 ─┐
                                          ├→ 判別器（Discriminator）→ 真/假
真實影像 ──────────────────────────────┘
```

- **生成器**：學習從噪音生成逼真影像
- **判別器**：學習區分真實和生成的影像
- **對抗訓練**：兩者互相競爭、共同進步
- **問題**：模式崩潰（Mode Collapse）、訓練不穩定

**GAN 變體：**
| 變體 | 特點 |
|------|------|
| **StyleGAN** | 高品質人臉生成，風格控制 |
| **CycleGAN** | 無配對影像轉換（如馬→斑馬） |
| **Pix2Pix** | 配對影像到影像轉換 |
| **SRGAN** | 超解析度影像增強 |

### 3.3 VAE（Variational Autoencoder）

```
輸入 → 編碼器 → 潛空間分佈（μ, σ）→ 取樣 → 解碼器 → 重建輸出
```

- 學習資料的潛在分佈
- 可用於影像生成和插值
- Stable Diffusion 使用 VAE 進行影像的編碼/解碼

## 📘 主題 5：效能最佳化

### 5.1 模型最佳化技術

| 技術 | 說明 | 效果 |
|------|------|------|
| **量化** | 降低權重精度（FP32→FP16→INT8） | 減少模型大小和推論時間 |
| **剪枝** | 移除不重要的權重或神經元 | 減少運算量 |
| **知識蒸餾** | 用大模型（教師）指導小模型（學生） | 小模型保持大部分性能 |
| **模型融合** | 合併多個運算層 | 減少記憶體讀寫 |

### 5.2 訓練最佳化

| 技術 | 說明 |
|------|------|
| **混合精度訓練** | FP16 計算 + FP32 主權重 |
| **梯度累積** | 模擬大 batch size |
| **資料平行** | 多 GPU 各自處理不同的資料批次 |
| **模型平行** | 將模型分佈到多個 GPU |
| **Pipeline Parallelism** | 將模型各層分配到不同 GPU |

### 5.3 推論最佳化

- **TensorRT**：自動進行層融合、精度校準、核心選擇
- **Dynamic Batching**：動態合併多個請求以提高 GPU 利用率
- **NVIDIA Triton**：多模型推論服務器，支援排程和資源管理

## 📘 主題 6：可信賴 AI（Trustworthy AI）

### 6.1 核心原則

| 原則 | 說明 |
|------|------|
| **公平性（Fairness）** | 模型不因種族、性別等產生歧視 |
| **透明度（Transparency）** | 模型決策過程可被理解 |
| **可解釋性（Explainability）** | 能解釋模型為何做出特定預測 |
| **隱私（Privacy）** | 保護訓練資料和使用者資料 |
| **安全性（Safety）** | 防止模型被濫用或產生有害輸出 |
| **可靠性（Reliability）** | 模型在各種條件下穩定運作 |

### 6.2 多模態特有的挑戰

- **生成影像偏見**：可能生成帶有文化或性別偏見的影像
- **Deepfake 風險**：逼真的虛假影像/影片
- **版權問題**：生成影像可能侵犯版權
- **水印技術**：為 AI 生成的內容添加不可見水印

### 6.3 NVIDIA AI 安全工具

- **NeMo Guardrails**：對話安全控制
- **NVIDIA AI Red Teaming**：系統性測試 AI 安全性
- **Content Safety Filtering**：過濾有害內容

**AI 模型中的可解釋性是指：**

### Q55
**部署多模態 AI 系統的公司應考慮以下哪些倫理問題？**

A) 僅 GPU 效能  
B) 偏見、隱私侵犯、版權問題和濫用的可能性  
C) 僅訓練資料大小

<details><summary>答案</summary>

**B) 偏見、隱私侵犯、版權問題和濫用的可能性**

部署多模態 AI 需考慮偏見（訓練資料偏見）、隱私（個人影像/語音）、版權（生成內容）和濫用風險（Deepfake）。
