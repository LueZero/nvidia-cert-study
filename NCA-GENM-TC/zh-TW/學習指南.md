# NVIDIA 認證助理：多模態生成式 AI（NCA-GENM-TC）

## 📋 考試概要

| 項目 | 內容 |
|------|------|
| **認證代碼** | NCA-GENM |
| **認證等級** | Associate（助理級） |
| **考試時間** | 60 分鐘 |
| **題數** | 50-60 題（多選題） |
| **費用** | \$125 USD |
| **語言** | 英文 |
| **有效期** | 2 年（可重考續證） |
| **先決條件** | 對生成式 AI 有基本了解 |
| **報名連結** | https://www.certiverse.com/#/checkout/nvidia/store-exam/NCA-GENM |

## 📚 考試範圍

### 涵蓋主題
- 核心機器學習與 AI 知識
- 資料分析與視覺化
- 實驗設計
- 多模態資料（文字、影像、音訊）
- 效能最佳化
- 軟體開發與工程
- 可信賴 AI（Trustworthy AI）

## 💡 備考建議

1. **先讀官方 Study Guide** — 最重要的第一步
2. **最具 CP 值**：Introduction to Transformer-Based NLP（\$30）+ Generative AI With Diffusion Models（\$90）
3. **重點主題**：多模態模型架構（Vision Transformer、CLIP 等）、Diffusion Models（Stable Diffusion）、跨模態融合、Trustworthy AI
4. **免費補充**：先看官方推薦的影片和 Blog（約 2.5 小時）
5. 這張認證強調多模態，要理解文字⇄影像⇄音訊的轉換技術
