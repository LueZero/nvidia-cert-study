## 🇬🇧 English

**NVIDIA Certified Associate - Data Science (TCU)**

This folder contains study materials for the NVIDIA Data Science certification:

| File | Description |
|------|-------------|
| [講義.md](講義.md) | Complete lecture notes organized by 6 exam domains |
| [題庫.md](題庫.md) | 120 practice questions with answers and explanations |

| Domain | Weight |
|--------|--------|

| Exploratory Data Analysis (EDA) | 15% |
| Statistics & Probability | 15% |
| Machine Learning | 25% |
| Deep Learning Fundamentals | 15% |
| MLOps & Deployment | 10% |

### Recommended Preparation

- [NVIDIA DLI - Data Science](https://www.nvidia.com/en-us/training/)
- RAPIDS cuDF / cuML official documentation
- Fundamentals of Accelerated Data Science with RAPIDS
