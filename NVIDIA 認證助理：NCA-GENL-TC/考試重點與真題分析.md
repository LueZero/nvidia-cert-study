## 🔥 真題考點分析（來自 ExamTopics 公開題目）

### ✅ 確認必考主題

#### 1. Word2Vec
**真題**：Which best describes Word2vec?
**答案**：A deep learning algorithm used to generate word embeddings from text data
- Word2Vec 是用來產生詞向量/word embeddings 的深度學習演算法
- 學習詞的分散式表示（distributed representation）
- 兩種架構：CBOW 和 Skip-gram

#### 2. Autoregressive Model
**真題**：In the context of language models, what does an autoregressive model predict?
**答案**：The probability of the next token in a text given the previous tokens
- 自迴歸模型根據之前的 tokens 預測下一個 token
- GPT 系列就是 autoregressive model
- 與 BERT（masked language model）不同

#### 3. Attention Mechanism
**真題**：In LLMs, what is the purpose of the attention mechanism?
**答案**：To assign weights to each word in the input sequence
- Attention 讓模型「注意」輸入中最相關的部分
- Self-attention: Query, Key, Value
- 計算每個 token 對其他 token 的權重

#### 4. Positional Encoding
**真題**：In the transformer architecture, what is the purpose of positional encoding?
**答案**：To add information about the order of each token in the input sequence
- Transformer 沒有 recurrence，需要位置資訊
- 使用 sin/cos 函數或 learned embeddings
- 讓模型知道 token 的順序

## 📋 Topic 3: LLM Architecture and Training — 必背重點

### 3.1 Transformer 架構（★★★ 超重點）

#### 核心組件
| 組件 | 功能 | 考試必記 |
|------|------|----------|
| Self-Attention | 計算 token 間關係 | Q × K^T / √d_k → Softmax → V |
| Multi-Head Attention | 多角度注意力 | h 個 heads 並行 |
| Positional Encoding | 提供位置資訊 | sin/cos 或 learned |
| Feed-Forward Network | 非線性轉換 | 兩層 Linear + GELU |
| Layer Normalization | 穩定訓練 | Pre-norm vs Post-norm |
| Residual Connection | 梯度流動 | x + Sublayer(x) |

#### Encoder vs Decoder
| 架構 | 代表模型 | 任務 |
|------|----------|------|
| Encoder-only | BERT, RoBERTa | 分類、NER、填空 |
| Decoder-only | GPT, LLaMA, Falcon | 文本生成 |
| Encoder-Decoder | T5, BART | 翻譯、摘要 |

### 3.2 LLM 訓練技術
| 技術 | 說明 |
|------|------|
| **Data Parallelism** | 資料分散到多 GPU |
| **Tensor Parallelism** | 矩陣運算分割到多 GPU |
| **Pipeline Parallelism** | 模型層分到不同 GPU |
| **Mixed Precision (FP16/BF16)** | 加速訓練、省記憶體 |
| **Gradient Checkpointing** | 用計算換記憶體 |
| **Flash Attention** | 記憶體效率的 attention |
| **ZeRO Optimization** | DeepSpeed 記憶體優化 |

### 3.3 重要 LLM 模型知識
| 模型 | 特點 | 必記 |
|------|------|------|

## 📋 Topic 5: RAG and LLM Applications — 必背重點

### 5.1 RAG 架構（★★★ 超級重要）

#### RAG 流程
```
Query → Embedding → Vector Search → Context Retrieval → LLM Generation
```

#### RAG 組件
| 組件 | 說明 | NVIDIA 解決方案 |
|------|------|----------------|
| Document Loading | 載入文件 | LlamaIndex |
| Chunking | 文件切分 | 固定/語意分割 |
| Embedding | 向量化 | NV-Embed, E5 |
| Vector Store | 向量資料庫 | Milvus, FAISS, Pinecone |
| Retrieval | 檢索相關文件 | Top-K, MMR |
| Generation | 生成答案 | NVIDIA NIM |

#### RAG vs Fine-tuning
| 面向 | RAG | Fine-tuning |
|------|-----|-------------|
| 知識更新 | 即時（更新文件庫） | 需要重新訓練 |
| 成本 | 較低 | 較高（GPU 資源） |
| 幻覺控制 | 有來源可追溯 | 較難控制 |
| 適用場景 | 知識密集型 | 任務適應 |
| 資料需求 | 文件庫 | 高品質訓練對 |

### 5.2 Embedding Models
| 模型 | 維度 | 特點 |
|------|------|------|
| OpenAI text-embedding-3 | 256-3072 | 可調維度 |
| NV-Embed | 4096 | NVIDIA 高效能 |
| E5-large | 1024 | 開源高效 |
| BGE | 768 | 中文友好 |

### 5.3 Vector Database
- **FAISS**: Facebook, in-memory, 適合原型
- **Milvus**: 分散式、生產級
- **Pinecone**: 全管理服務
- **Weaviate**: 支援混合搜尋

## 📋 Topic 6: LLM Deployment and Optimization — 必背重點

### 6.1 推理優化技術（★★★）
| 技術 | 說明 | 加速效果 |
|------|------|----------|
| **Quantization** | 降低精度（FP16→INT8→INT4） | 2-4x 加速 |
| **KV Cache** | 快取 Key-Value 避免重算 | 減少計算 |
| **Continuous Batching** | 動態批次處理 | 提高 GPU 利用率 |
| **Speculative Decoding** | 小模型先猜、大模型驗證 | 2-3x 加速 |
| **Flash Attention** | IO-aware attention | 記憶體效率 |
| **Paged Attention (vLLM)** | 分頁管理 KV cache | 減少記憶體浪費 |
| **Model Parallelism** | 大模型拆分多 GPU | 支援超大模型 |

### 6.2 NVIDIA 推理工具鏈
| 工具 | 用途 |
|------|------|
| **TensorRT-LLM** | LLM 推理加速引擎 |
| **Triton Inference Server** | 多模型服務框架 |
| **NVIDIA NIM** | 容器化微服務部署 |
| **vLLM** | 開源 LLM 推理引擎 |

### 6.3 Fine-tuning 方法（★★★）
| 方法 | 參數量 | 說明 |
|------|--------|------|
| Full Fine-tuning | 100% | 更新所有參數 |
| **LoRA** | ~0.1% | Low-Rank Adaptation |
| **QLoRA** | ~0.1% | 量化 + LoRA |
| P-tuning | < 0.1% | Soft prompts |
| Adapter | ~1-5% | 插入小型適配層 |
| Prefix-tuning | < 0.1% | 學習前綴向量 |

#### LoRA 原理（★★★ 必考）
- 凍結原始權重矩陣 W
- 新增低秩分解: W + ΔW = W + BA
- A: d×r, B: r×k（r << d, k）
- 大幅減少可訓練參數（通常 r=8 或 16）
- 記憶體需求低、訓練快、效果接近全量微調
