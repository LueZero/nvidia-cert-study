## 📚 考試範圍與比重

### 1. Data Manipulation and Preparation（資料操作與準備）— 23%
- 使用 NVIDIA cuDF 和 pandas 進行資料整合、聯結和操作
- 資料清理、品質處理與治理合規
- 使用 RAPIDS、Dask 或 Spark 的 GPU 加速 ETL 工作流程
- 數值和類別變數的特徵工程
- 處理類別不平衡和生成合成資料
- 降維和資料取樣
- 使用 Parquet 和現代框架進行高效處理和儲存

### 2. Machine Learning With RAPIDS（使用 RAPIDS 的機器學習）— 16%
- 使用 NVIDIA cuML 和 XGBoost 的 GPU 加速模型訓練
- 迴歸、分類和分群技術
- 模型評估、比較和泛化評估
- 超參數調校和最佳化
- 交叉驗證方法
- 效能指標和混淆矩陣解讀

### 3. Data Science Pipelines and Workflow Automation（資料科學管線）— 13%
- 端到端資料科學管線設計
- 特徵工程、選擇和轉換
- 減輕欠擬合和過擬合
- 資料集擴增和整合
- 工作流程自動化和可擴展性
- 使用 RAPIDS 和 Dask 建構可重現的管線

### 4. Descriptive Analysis and Visualization（描述性分析與視覺化）— 13%
- 探索性資料分析（EDA）和描述統計
- 資料視覺化
- 為不同分析目標選擇適當的圖表
- 假設檢定和統計顯著性評估
- 解讀資料中的模式、趨勢和關係

### 5. Foundations of Accelerated Data Science（加速資料科學基礎）— 12%
- Python 資料分析基礎（NumPy、pandas、Jupyter）
- GPU 加速核心概念和優勢
- CPU vs GPU 工作負載與記憶體傳輸最佳化
- 端到端資料科學工作流程（擷取、ETL、清理、轉換）
- 分散式 vs GPU 加速計算框架
- 模型參數、調校、過擬合 vs 欠擬合概念

### 6. Introductory MLOps Practices（MLOps 入門實務）— 10%
- 監控和最佳化 ML 管線效能與可靠性
- 使用 MLflow、Weights & Biases 管理和追蹤實驗
- 模型儲存、載入和預測生成
- 監控生產模型的飄移和效能退化
- 管理模型 artifacts 和配置的可重現性
- 基準測試工作流程和選擇最佳硬體

### 7. Advanced Data Structures（進階資料結構）— 7%
- 時間序列資料處理、分割和預測評估
- 使用 cuDF 插值管理缺失或不規則的時間戳
- CPU vs GPU 效能（時間分析）
- 圖形資料表示和分析
- 節點重要性評估和網路關係視覺化

### 8. Software and Environment Management（軟體與環境管理）— 6%
- 維護環境檔案以確保可重現性
- 使用 Conda、PIP 或 Docker 配置可重現的 Python 環境
- 管理軟體相依性和多使用者環境
- GPU 環境檢查（driver/CUDA/RAPIDS 相容性、nvidia-smi）
- Git 版本控制基礎

## 💡 備考建議

1. **先讀官方 Study Guide** — 瞭解考試範圍和格式
2. **核心必修**：Accelerating End-to-End Data Science Workflows — 涵蓋最多考試主題
3. **重點技術**：RAPIDS（cuDF、cuML、cuGraph）、Dask、XGBoost GPU、pandas API 相容、Parquet 格式
4. **佔比最高（23%）的是資料操作與準備** — 重點掌握 cuDF 操作
5. 這張認證要求 1-2 年實務經驗，對 RAPIDS 生態系不熟悉建議先完成官方課程
6. 練習考試時間管理：50-60 題 / 60 分鐘
