merged = cudf.merge(df1, df2, on='key', how='inner')

### 2.3 模型評估指標

| 指標 | 用途 | 計算 |
|------|------|------|
| **Accuracy** | 整體正確率 | 正確預測 / 全部 |
| **Precision** | 預測正例中的正確率 | TP / (TP + FP) |
| **Recall** | 實際正例中被找到的比率 | TP / (TP + FN) |
| **F1 Score** | Precision 和 Recall 的調和平均 | 2 × P×R / (P+R) |
| **AUC-ROC** | 分類器區分能力 | ROC 曲線下面積 |
| **RMSE** | 迴歸誤差 | 均方根誤差 |
| **R²** | 迴歸擬合度 | 模型解釋變異的比例 |

**混淆矩陣（Confusion Matrix）：**
```
              預測正   預測負
實際正    │   TP    │   FN   │
實際負    │   FP    │   TN   │
```

### 2.4 超參數調校

| 方法 | 說明 | 效率 |
|------|------|------|
| **Grid Search** | 窮舉所有組合 | 低（但全面） |
| **Random Search** | 隨機取樣組合 | 中 |
| **Bayesian Optimization** | 智能搜尋最佳組合 | 高 |

### 2.5 交叉驗證

```
K-Fold Cross Validation (K=5):
Fold 1: [Test] [Train] [Train] [Train] [Train]
Fold 2: [Train] [Test] [Train] [Train] [Train]
Fold 3: [Train] [Train] [Test] [Train] [Train]
Fold 4: [Train] [Train] [Train] [Test] [Train]
Fold 5: [Train] [Train] [Train] [Train] [Test]
→ 取 5 次分數的平均值
```

- 減少評估的變異性
- 更可靠的效能估計
- **Stratified K-Fold**：保持每折中類別比例一致

### 3.2 過擬合 vs 欠擬合

| 問題 | 原因 | 解決方法 |
|------|------|----------|
| **過擬合** | 模型太複雜、資料太少 | 正則化、Dropout、更多資料、Early Stopping |
| **欠擬合** | 模型太簡單 | 增加模型複雜度、更多特徵、更長訓練 |

**診斷方法：**
- 訓練損失低、驗證損失高 → 過擬合
- 訓練損失和驗證損失都高 → 欠擬合

### 3.3 使用 RAPIDS 和 Dask 的可重現管線

**Dask 的角色：**

**為什麼 GPU 更快？**
- **平行處理**：數千個核心同時工作
- **高記憶體頻寬**：HBM 提供 TB/s 等級的頻寬
- **適合的工作負載**：矩陣運算、向量操作、批次處理

**CPU vs GPU 工作負載選擇：**
| 場景 | 選擇 | 原因 |
|------|------|------|
| 小資料集（< 10MB） | CPU | GPU 的啟動開銷抵消了速度優勢 |

| 向量化操作 | GPU | 可大規模平行化 |

### 5.3 記憶體傳輸最佳化

- **Host（CPU）→ Device（GPU）** 傳輸是瓶頸
- **最佳做法**：減少 CPU↔GPU 資料搬移次數
- **GPU Direct**：GPU 直接存取儲存/網路，繞過 CPU
- **Unified Memory**：自動管理 CPU/GPU 記憶體遷移

**在分割時間序列資料進行模型評估時，你應該：**

C) 在分割前打亂所有資料  
D) 僅使用最新的資料進行訓練  

<details><summary>答案</summary>

**B) 保持時間順序——訓練資料在測試資料之前**

</details>
