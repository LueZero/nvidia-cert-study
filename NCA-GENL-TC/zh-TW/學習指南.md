# NVIDIA 認證助理：Gen AI LLMs（NCA-GENL-TC）

## 📋 考試概要

| 項目 | 內容 |
|------|------|
| **認證代碼** | NCA-GENL |
| **認證等級** | Associate（助理級） |
| **考試時間** | 60 分鐘 |
| **題數** | 50-60 題（多選題） |
| **費用** | \$125 USD |
| **語言** | 英文 |
| **有效期** | 2 年（可重考續證） |
| **先決條件** | 對生成式 AI 和大型語言模型有基本了解 |
| **報名連結** | https://www.certiverse.com/#/checkout/nvidia/store-exam/NCA-GENL |

---

## 📚 考試範圍

### 涵蓋主題
- 機器學習與神經網路基礎
- 提示工程（Prompt Engineering）
- 對齊（Alignment）
- 資料分析與視覺化
- 實驗設計
- 資料前處理與特徵工程
- 軟體開發
- 用於 LLM 的 Python 函式庫
- LLM 整合與部署

## 💡 備考建議

1. **先讀官方 Study Guide** — 掌握考試方向
2. **最具 CP 值的課程**：Introduction to Transformer-Based NLP（\$30/6hr）— 最便宜且涵蓋核心
3. **重點主題**：Transformer 架構、Prompt Engineering 技巧、RAG 概念、LLM 微調方法、RLHF 對齊
4. **免費補充**：先看官方推薦的 Blog 和影片（約 2 小時就能看完）
5. 練習考試時間管理：50-60 題 / 60 分鐘
