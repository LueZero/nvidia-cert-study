## 🔥 真題考點分析（來自 ExamTopics 公開題目）

### ✅ 確認必考主題（含真題原文）

#### 1. Word2Vec ⭐
> **真題**：Which best describes Word2vec?  
> **答案**：A deep learning algorithm used to generate word embeddings from text data

**白話解釋**：Word2Vec 是把文字變成數字向量的工具。它能讓意思相近的詞（如「國王」和「皇帝」）在向量空間中距離很近。

| 重點 | 說明 |
|------|------|
| 功能 | 產生詞向量（word embeddings） |
| 兩種架構 | CBOW（周圍詞預測中間詞）、Skip-gram（中間詞預測周圍詞） |
| vs BERT | Word2Vec 是固定向量；BERT 根據上下文動態變化 |

---

#### 2. Autoregressive Model ⭐
> **真題**：In the context of language models, what does an autoregressive model predict?  
> **答案**：The probability of the next token in a text given the previous tokens

**白話解釋**：像打字時的自動完成功能 — 根據你已經打的字，預測下一個最可能出現的字。GPT 就是這種模型。

---

#### 3. Attention Mechanism ⭐
> **真題**：In LLMs, what is the purpose of the attention mechanism?  
> **答案**：To assign weights to each word in the input sequence

**白話解釋**：就像閱讀時「重點標記」— 模型會自動判斷哪些字詞最重要，給它們更高的注意力權重。

---

#### 4. Positional Encoding ⭐
> **真題**：In the transformer architecture, what is the purpose of positional encoding?  
> **答案**：To add information about the order of each token in the input sequence

**白話解釋**：Transformer 一次看所有字（不像人一個字一個字讀），所以需要額外告訴它「這個字排在第幾位」。

## 📋 領域 1：核心 ML 與 AI 知識 — 必背重點（30%）

### 基礎 ML 概念

| 概念 | 一句話解釋 | 代表例子 |
|------|-----------|---------|
| 監督式學習 | 有標準答案的學習 | 分類、迴歸 |
| 非監督式學習 | 沒有標準答案，找規律 | 聚類、降維 |
| 自監督學習 | 資料自己產生標籤 | GPT 預訓練 |
| 遷移學習 | 學過的知識用到新任務 | Pre-train → Fine-tune |
| Zero-shot | 沒看過範例就能做 | 直接下指令 |
| Few-shot | 看幾個範例就會做 | 給 2-3 個示範 |

### Word Embeddings 比較（★★★ 已出真題）

| 方法 | 特點 | 關鍵差異 |
|------|------|---------|
| Word2Vec | 每個詞一個固定向量 | 不考慮上下文（bank = 同一向量） |
| GloVe | 全域統計 + 矩陣分解 | 同樣是固定向量 |
| FastText | 子字詞級別 | 能處理沒見過的詞 |
| BERT Embeddings | 同一個詞，不同句子 = 不同向量 | **上下文相關**（最大突破） |

### Transformer 架構（★★★ 超重點）

| 組件 | 功能（白話） | 考試必記 |
|------|------------|---------|
| Self-Attention | 每個字「看」其他所有字，判斷誰跟它最相關 | Q×K^T / √d_k → Softmax → V |
| Multi-Head | 多個角度同時關注（語法、語義各看一次） | h 個 heads 並行 |
| Positional Encoding | 告訴模型字的順序 | sin/cos 或 learned |
| FFN | 對每個位置做非線性變換 | 兩層 Linear + GELU |
| Layer Norm | 穩定訓練不爆掉 | Transformer 用 LayerNorm |
| Residual Connection | 讓梯度能順利回傳 | x + Sublayer(x) |

### LLM 架構類型

| 類型 | 代表模型 | 做什麼用 |
|------|---------|---------|
| Encoder-only | BERT | 理解文本（分類、填空） |
| Decoder-only | GPT、LLaMA | 生成文本（寫作、對話） |
| Encoder-Decoder | T5、BART | 轉換文本（翻譯、摘要） |

### Prompt Engineering 技巧

| 技巧 | 說明 | 何時用 |
|------|------|-------|
| Zero-shot | 只給指令，不給範例 | 簡單任務 |
| Few-shot | 給 2-5 個範例 | 需要特定格式 |
| Chain-of-Thought | "Let's think step by step" | 數學/推理 |
| ReAct | 推理+行動交替 | 需要查資料的問題 |

### RLHF 流程（★★★ 必考）

```
Step 1: SFT（用好的回答微調模型）
    ↓
Step 2: 訓練獎勵模型（人類排序哪個回答好）
    ↓
Step 3: PPO 強化學習（用獎勵模型指導模型改進）
```

| 比較 | RLHF | DPO |
|------|------|-----|
| 需要獎勵模型？ | 是 | 否 |
| 實作難度 | 高 | 低 |
| 穩定性 | 較低 | 較高 |
| 效果 | 驗證有效 | 接近 RLHF |

## 📋 領域 3：實驗 — 必背重點（22%）

### Fine-tuning 方法比較（★★★）

| 方法 | 訓練參數量 | 白話說明 |
|------|-----------|---------|
| Full Fine-tuning | 100% | 全部重新訓練（最貴） |
| **LoRA** | ~0.1% | 只加小矩陣微調（最熱門） |
| QLoRA | ~0.1% | 量化 + LoRA（省更多記憶體） |
| Adapter | ~1-5% | 在層之間插小網路 |
| Prefix Tuning | <0.1% | 學習前綴向量 |

### LoRA 原理（★★★ 必考）

**白話**：不動原始模型，旁邊加一條「旁路」來學新東西。這條旁路很小（rank=8~64），所以又快又省資源。

### 評估指標

| 指標 | 用途 | 白話解釋 |
|------|------|---------|
| **BLEU** | 翻譯品質 | 算「生成文字」和「標準答案」有多少詞重疊（**精確率**） |
| **ROUGE** | 摘要品質 | 算「標準答案」中有多少被「生成文字」覆蓋到（**召回率**） |
| **Perplexity** | 語言模型能力 | 模型的「驚訝程度」，越低越好 |
| **F1-Score** | 分類品質 | 精確率和召回率的平均分數 |

> 🚨 **考試陷阱**：BLEU 分數高 ≠ 模型字彙量增加。只代表更接近參考文本！

### 多 GPU 訓練方式

| 方式 | 白話說明 |
|------|---------|
| Data Parallelism | 資料切成多份，每張 GPU 處理一份 |
| Tensor Parallelism | 一個矩陣切開，分給多張 GPU 算 |
| Pipeline Parallelism | 模型不同層放不同 GPU |
| All-Reduce | 所有 GPU 同步梯度的通訊方式 |

## 📋 領域 4：數據分析與視覺化 — 必背重點（14%）

### EDA（探索性資料分析）

模型訓練前的「健康檢查」，找出資料問題：
- 類別分布是否平衡？
- 文本長度統計
- 有無重複 / 空值 / 誤標？

### Tokenization 方法

| 方法 | 用在哪 | 合併策略 |
|------|--------|---------|
| BPE | GPT 系列 | 合併最頻繁的字元對 |
| WordPiece | BERT | 合併似然度最高的 |
| SentencePiece | LLaMA, T5 | 語言無關，直接處理原始文本 |

### RAPIDS / cuDF

- GPU 加速的資料分析框架
- 與 Pandas 語法相容（直接替換 `import pandas` → `import cudf`）
- 利用 Apache Arrow 格式

## 📋 領域 5：可信賴的 AI — 必背重點（10%）

### 負責任 AI 核心原則

| 原則 | 說明 |
|------|------|
| 公平性 | 不因性別、種族等產生歧視 |
| 透明度 | 決策過程可解釋 |
| 隱私保護 | 保護個人資料 |
| 可問責性 | 明確責任歸屬 |
| 安全性 | 不造成傷害 |

### NeMo Guardrails
- 限制 LLM 回覆的邊界（主題、格式、安全）
- 防止越獄（jailbreak）攻擊
- 輸入/輸出雙向過濾

### Content Credentials（內容來源憑證）
- **C2PA** 標準：追溯 AI 生成內容的來源
- **CAI** 聯盟：Adobe 主導推動
- 用途：對抗 deepfake，確認內容真偽

1. **Transformer 架構是核心** — 注意力公式、位置編碼、Encoder vs Decoder 必考
2. **RAG 流程必熟** — 組件、流程、vs Fine-tuning 比較
3. **RLHF/DPO** — 理解流程差異
4. **LoRA** — 原理和優勢
5. **NVIDIA 工具** — 每個工具的定位要清楚
6. **不要死背公式** — 重點是「理解概念」和「知道什麼時候用什麼」
