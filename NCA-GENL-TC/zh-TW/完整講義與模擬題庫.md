## 📘 領域 1：核心機器學習與 AI 知識（30%）

### 神經網路基礎

| 概念 | 白話說明 |
|------|---------|
| 激活函數 | 讓網路能學非線性關係。ReLU 最通用；Transformer 用 GELU；分類用 Softmax |
| 損失函數 | 衡量預測和真實的差距。分類用 Cross-Entropy；迴歸用 MSE |
| 反向傳播 | 用鏈式法則從後往前算梯度，告訴每個權重該怎麼調 |
| 優化器 | AdamW 是 LLM 訓練標準（自適應學習率 + weight decay 解耦） |
| 正則化 | Dropout（隨機停用神經元）、Weight Decay、Layer Norm |

### Transformer 架構

**核心公式**：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

| 組件 | 作用（白話） |
|------|------------|
| Self-Attention | 每個字看所有字，算出「誰最重要」 |
| Multi-Head | 多角度同時看（語法頭、語義頭...） |
| Positional Encoding | 告訴模型字的順序（sin/cos 或 RoPE） |
| FFN | 每個位置做非線性變換 |
| Layer Norm + Residual | 穩定訓練 + 讓梯度順利傳回 |

### LLM 三大架構

| 類型 | 代表 | 注意力 | 用途 |
|------|------|--------|------|
| Encoder-only | BERT | 雙向 | 理解（分類、NER） |
| **Decoder-only** | GPT, LLaMA | 單向 | 生成（對話、寫作） |
| Encoder-Decoder | T5, BART | 雙向+單向 | 轉換（翻譯、摘要） |

### Word Embeddings

| 方法 | 關鍵差異 |
|------|---------|
| Word2Vec | 固定向量（不看上下文） |
| BERT Embedding | **動態向量**（同詞不同句=不同向量） |

### Prompt Engineering

| 技巧 | 何時用 |
|------|-------|
| Zero-shot | 簡單任務，只給指令 |
| Few-shot | 需要特定格式，給 2-5 個範例 |
| Chain-of-Thought | 數學/推理，"Let's think step by step" |
| ReAct | 需要查資料時（推理+行動交替） |

### Alignment（對齊）

**RLHF 三步驟**：SFT → 獎勵模型 → PPO  
**DPO**：不需要獎勵模型，直接從偏好資料學習（更簡單穩定）

## 📘 領域 3：實驗（22%）

### Fine-tuning 方法

| 方法 | 參數量 | 說明 |
|------|--------|------|
| Full FT | 100% | 全部重練（最貴） |
| **LoRA** | ~0.1% | 凍結原始，加小旁路（最熱門） |
| QLoRA | ~0.1% | 量化 + LoRA（更省記憶體） |

**LoRA 公式**：$W' = W + BA$（B 和 A 是小矩陣，rank 通常 8~64）

### 評估指標

| 指標 | 衡量什麼 | 重點記憶 |
|------|---------|---------|
| **BLEU** | 翻譯品質 | **精確率**（我的詞有多少在答案裡） |
| **ROUGE** | 摘要品質 | **召回率**（答案的詞有多少被我覆蓋） |
| **Perplexity** | 語言模型能力 | 越低越好（模型越不驚訝） |
| **F1** | 分類品質 | 精確率和召回率的平衡 |

> 🚨 BLEU 高 ≠ 字彙量增加（只代表接近參考文本）

### 量化

把模型精度降低以省空間加速：FP32→FP16→INT8→INT4  
→ **目的是省記憶體和加速，不是提升準確度**

### 多 GPU 訓練

| 方式 | 說明 |
|------|------|
| Data Parallelism | 資料切多份，各 GPU 算一份 |
| Tensor Parallelism | 矩陣切開，多 GPU 合算 |
| Pipeline Parallelism | 不同層放不同 GPU |
| All-Reduce | 同步所有 GPU 的梯度 |
