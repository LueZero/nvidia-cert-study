# NVIDIA Certification Associate Study Resources

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> Open-source study notes and practice question banks for NVIDIA certification exams, covering four certifications.

## 📚 Certifications Covered

| Code | Certification | Notes | Questions |
|------|--------------|-------|-----------|
| NCA-ADS-TCU | Data Science | [Notes](NVIDIA%20認證助理：NCA-ADS-TCU/講義.md) | [Questions](NVIDIA%20認證助理：NCA-ADS-TCU/題庫.md) |
| NCA-GENL-TC | Generative AI LLM | [Notes](NVIDIA認證助理：NCA-GENL-TC/講義.md) | [Questions](NVIDIA認證助理：NCA-GENL-TC/題庫.md) |
| NCA-AIIO-TC | AI Infrastructure & Operations | [Notes](NVIDIA認證助理：NCA-AIIO-TC/講義.md) | [Questions](NVIDIA認證助理：NCA-AIIO-TC/題庫.md) |
| NCA-GENM-TC | Generative AI Multimodal | [Notes](NVIDIA%20認證助理：NCA-GENM-TC/講義.md) | [Questions](NVIDIA%20認證助理：NCA-GENM-TC/題庫.md) |

## 🎯 Features

- 📖 **Comprehensive Notes**: Written based on official exam blueprints with code examples, architecture diagrams, and formulas
- 📝 **Practice Questions**: 120 questions per certification, distributed by domain weight, with detailed explanations
- 🌐 **Traditional Chinese**: All content in Traditional Chinese, technical terms in English
- ✅ **Balanced Answers**: A/B/C/D evenly distributed (25% each)

## ⚠️ Disclaimer

- This is an **unofficial** community study resource, not affiliated with NVIDIA
- Content is based on publicly available exam blueprints and study guides
- Practice questions are original, not leaked exam questions
- Please use alongside [NVIDIA official training courses](https://www.nvidia.com/en-us/training/)
