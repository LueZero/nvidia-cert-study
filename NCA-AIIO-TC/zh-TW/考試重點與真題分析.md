## 🔥 真題考點分析（來自 ExamTopics 公開題目）

### ✅ 確認必考主題

#### 1. Training vs Inference 架構差異
**真題**：Training architecture is focused on optimizing performance while inference architecture is focused on reducing latency.
- Training：大批量、高吞吐量、需要大量 GPU 記憶體
- Inference：低延遲、小批量、需要高效率

#### 2. NVIDIA Merlin — 推薦系統框架
**真題**：NVIDIA Merlin is typically used for **Recommender systems**
- Merlin 是 NVIDIA 的推薦系統 end-to-end 框架
- 用於 ETL、Training、Inference 的推薦系統全流程

#### 3. CUDA 平台
**真題**：CUDA allows developers to program in popular languages and express parallelism through extensions
- CUDA = Compute Unified Device Architecture
- 支援 C/C++、Python、Fortran 等語言
- 透過 extensions 表達平行運算

#### 4. AI 採用增長因素
**真題**：High Powered GPUs + Large amounts of data（選兩個）
- GPU 運算能力的提升
- 大量數據的可用性
- 不是 Moore's Law 或 Rule-based ML

## 📋 Domain 2: AI Infrastructure（40%）必背重點

### 2.1 GPU 硬體架構（★★★ 超級重要）

#### NVIDIA H100 Hopper 架構關鍵數據
| 規格 | H100 SXM5 | A100 | 比較 |
|------|-----------|------|------|
| 製程 | TSMC 4N | TSMC 7nm | 更先進 |
| 電晶體 | 800 億 | 542 億 | 1.5x |
| SM 數量 | 132 | 108 | +22% |
| FP32 Cores/SM | 128 | 64 | 2x |
| Tensor Cores/SM | 4（第四代） | 4（第三代） | 新增 FP8 |
| HBM | 80GB HBM3 | 80GB HBM2e | 頻寬 2x |
| 記憶體頻寬 | 3 TB/s | 2 TB/s | 1.5x |
| NVLink | 第四代 18 links | 第三代 12 links | 900 vs 600 GB/s |
| TDP | 700W | 400W | 更高功耗 |
| FP8 Tensor | 2000/4000 TFLOPS | N/A | 新功能 |

#### H100 核心新功能（★★★ 必考）
1. **Transformer Engine** — 智能切換 FP8/FP16，加速 Transformer 訓練 9x、推理 30x
2. **FP8 資料格式** — E4M3（精度高）和 E5M2（範圍大）
3. **第四代 Tensor Cores** — 比 A100 快 6x
4. **Thread Block Clusters** — 新的 CUDA 編程層級
5. **DPX Instructions** — 動態程式設計加速 7x
6. **第二代 MIG** — 3x 運算能力/實例

### 2.2 NVLink / NVSwitch（★★★ 超高頻考點）
| 技術 | 說明 | 關鍵數字 |
|------|------|----------|
| NVLink（第四代） | GPU-to-GPU 高速互連 | 900 GB/s 總頻寬 |
| NVSwitch（第三代） | 節點內 GPU 互連交換器 | 64 ports, 13.6 Tb/s |
| NVLink Network | 跨節點 GPU 互連 | 最多 256 GPU |
| vs PCIe Gen 5 | NVLink 是 PCIe 的 7x | 128 GB/s vs 900 GB/s |

### 2.3 DGX 系統（★★★ 必考）

#### DGX H200 規格
| 規格 | DGX H200 |
|------|----------|
| GPU | 8x H200 Tensor Core GPU |
| GPU Memory | 1,128 GB 總計 |
| 性能 | 32 petaFLOPS FP8 |
| NVSwitch | 4x |
| CPU | Dual Intel Xeon Platinum 8480C（112 cores） |
| 系統記憶體 | 2 TB |

#### DGX SuperPOD
- 最多 32 nodes, 256 GPUs
- 使用 NVLink Switch System 互連

## 📋 Domain 3: AI Operations（22%）必背重點

### 3.1 Multi-Instance GPU（MIG）★★★
- 將一張 GPU 分割成最多 **7 個** 獨立 GPU 實例
- 每個實例有專用的 SM、記憶體、NVDEC、NVJPG
- H100 第二代 MIG：3x 運算能力/實例
- 支援 Confidential Computing（TEE）
- 適用場景：多租戶、推理服務、開發測試

### 3.2 vGPU（Virtual GPU）
- 允許多個虛擬機共享一張 GPU
- 類型：vCS（Compute Server）、vWS（Workstation）
- 支援 VMware vSphere、KVM、Citrix
- 用於 VDI、遠端工作站、多租戶雲端

### 3.3 容器化與 Kubernetes
| 技術 | 用途 |
|------|------|
| NVIDIA Container Toolkit | GPU 容器支援 |
| NVIDIA GPU Operator | K8s 自動管理 GPU 驅動 |
| NVIDIA Device Plugin | K8s GPU 資源排程 |
| NGC Catalog | GPU 優化容器映像庫 |

### 3.4 監控與管理
| 工具 | 功能 |
|------|------|
| nvidia-smi | GPU 狀態查看 |
| DCGM (Data Center GPU Manager) | 企業級 GPU 監控 |
| NVIDIA Base Command | DGX 叢集管理 |
| Prometheus + Grafana | 監控視覺化 |
